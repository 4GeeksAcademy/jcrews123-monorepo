# Syllabus-first milestone work

**Scope:** Agent-requested — apply when starting, reviewing, or submitting any company milestone (MS-0 through MS-10).

## Rule

Before implementing or accepting a milestone as complete:

1. Read [`memory-bank/syllabusReference.md`](../../memory-bank/syllabusReference.md) for the correct project README and context URLs.
2. Fetch and read the **syllabus project README** from [ai-engineering-syllabus](https://github.com/4GeeksAcademy/ai-engineering-syllabus) — not just local memory bank summaries.
3. Cross-check every **evaluation criterion** in that README against the repo.
4. Do **not** treat code merged from a prior milestone as sufficient if the current milestone README requires:
   - A new framework (e.g. Next.js instead of static HTML)
   - Integration of prior milestones (e.g. importing `apps/operations` into backoffice)

## When unsure

Fetch the syllabus README before writing code. Local `archive/ms-N-plan/` is historical; the syllabus is the grading spec.
